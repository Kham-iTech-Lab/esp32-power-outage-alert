# ESP32 แจ้งเตือนไฟบ้านดับเข้า Telegram

โค้ดประกอบคลิปของ **K iTech Review** (TikTok) / **Kham iTech Lab** (YouTube · Facebook)

ไฟบ้านดับเมื่อไร มือถือเด้งแจ้งทันที พอไฟกลับมาก็แจ้งอีกรอบ พร้อมบอกว่าดับไปนานเท่าไร ใช้บอท Telegram ตัวเดียวกับโปรเจกต์ [แจ้งเตือนประตูเปิด](https://github.com/Kham-iTech-Lab/esp32-telegram-door) ได้เลย

## ของที่ต้องใช้

- บอร์ด ESP32 (DevKit V1 หรือรุ่นที่มีขา GPIO 34)
- แบตสำรองเลี้ยงบอร์ด: พาวเวอร์แบงก์ที่ชาร์จไปใช้ไปได้ (pass-through) หรือ UPS ตัวเล็ก
- อะแดปเตอร์ 5V อีก 1 ตัว (ไว้ตรวจว่าไฟบ้านมาไหม)
- ตัวต้านทาน 10kΩ และ 20kΩ อย่างละ 1 ตัว
- เราเตอร์ที่มีไฟสำรอง (UPS) ไม่งั้นตอนไฟดับจะส่งข้อความไม่ออก

## ต่อวงจร

```
อะแดปเตอร์ 5V (+) --- 10k ---+--- GPIO 34
                              |
                             20k
                              |
อะแดปเตอร์ 5V (-) ------------+--- GND (ESP32)
```

ตรงกลางจะได้ราว 3.3V (5 × 20 ÷ 30) ปลอดภัยกับขา ESP32

> ⚠️ ห้ามต่อไฟบ้าน 220V เข้าบอร์ดตรง ๆ เด็ดขาด ใช้อะแดปเตอร์เท่านั้น

## ติดตั้ง

1. สร้างบอทกับ @BotFather และหาเลขแชท (ดูวิธีในโปรเจกต์แจ้งเตือนประตู)
2. คัดลอก `secrets.example.h` เป็น `secrets.h` แล้วใส่ชื่อ Wi-Fi, รหัส, รหัสบอท และเลขแชท
3. เปิด `esp32_power_outage_alert.ino` ใน Arduino IDE เลือกบอร์ด ESP32 Dev Module แล้วอัปโหลด
4. ลองถอดปลั๊กอะแดปเตอร์ 5V ออก ราว 3 วินาทีมือถือจะเด้ง "ไฟบ้านดับ!"

## ปรับแต่ง

- `CONFIRM_MS` เวลาที่ต้องดับค้างก่อนแจ้ง (ค่าเริ่มต้น 3 วินาที กันไฟกะพริบ)
- `RETRY_MS` ส่งไม่สำเร็จ ลองใหม่ทุกกี่มิลลิวินาที
- `SENSE_PIN` เปลี่ยนขาได้ แต่ต้องเป็นขาที่รับสัญญาณดิจิทัลได้

`secrets.h` อยู่ใน `.gitignore` แล้ว อย่าอัปรหัสจริงขึ้นอินเทอร์เน็ต
